# pc98-sasi-analysis

PC-9801UX の純正のハードディスクユニット **PC-9801UX-31** と、C-bus の SASI インターフェースボード **PC-9801-27** の解析結果。
実物の回路の導通の測定、写真、公開されている資料（NEC のテクニカルデータブック、SASI の規格 X3T9.3 など）の要約、ROM のダンプから読み取った振る舞いをまとめた。

| 文書 | 中身 |
|---|---|
| [ux31.md](ux31.md) | UX-31 のユニット、ホストアダプタの回路と論理（式）、コントローラのファームウェアの振る舞い、ドライブ D3126、SASI の規格との突き合わせ |
| [pc9801-27.md](pc9801-27.md) | PC-9801-27 の ROM の構成、ボードの設定、部品、ROM の選択の回路、機種ごとに使われる BIOS |
| [ux21-measurements.md](ux21-measurements.md) | PC-9801UX21 の実機での I/O 82h、31h、選択、82h を読むループの時間の測定（2026-11-14） |
| [references.md](references.md) | 参考資料 |

> [!NOTE]
> ROM（NEC の SASI BIOS、UX-31 のコントローラのファームウェア）のダンプ、逆アセンブル、ROM の中の番地と命令の並びは公開しない。
> ここに書いたのは、外から見える振る舞い（受け付ける命令、センス、手順）だけ。

## タグ

本文の段落や項目には、出どころを示すタグを付けた（閉じタグまでが範囲。見出しに付けたものは、次の見出しまでに効く）。

| タグ | 意味 |
|---|---|
| `[測定] … [/測定]` | 実物での測定や読み出しの結果（テスター、ロジックの導通、実機の I/O の読み出しなど） |
| `[資料 n] … [/資料]` | 参考資料 n に書いてあること（[references.md](references.md)） |
| `[解析] … [/解析]` | 回路や ROM のダンプから読み取ったこと（実機で動かして確かめてはいない） |
| `[要確認] … [/要確認]` | まだ確かめていないことと、確かめ方 |
| `[推測] … [/推測]` | 推測（図の中だけに残る） |

信号名の `#` は負論理（REQ#、SASI_CONFIG#）。C-bus の信号は末尾の数字が論理（1 = 正、0 = 負）なので `#` を付けない（IOR0、DACK0）。
SASI の `#` のない REQ、ACK などは、受信したあとの正論理の意味。
